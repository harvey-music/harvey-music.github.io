隐私说明

这个站点没有广告、没有统计脚本、没有用户画像。下面写清楚留言板与账号体系具体会碰到哪些数据。

1. 收集哪些信息

  • 注册时：邮箱、密码、昵称。密码由认证服务以哈希形式保存，本站任何人（包括站长）都看不到明文。
  • 使用中：你填写的简介、发布的留言正文与时间。
  • 风控：发表留言时的 IP 地址与浏览器标识（User-Agent），仅站长可见，用于识别刷屏和追责。

不收集手机号、真实姓名、身份证件、位置、通讯录，也不接入任何第三方统计或广告 SDK。

2. 存在哪里

  • 页面本身是静态文件，托管在 GitHub Pages 上，不写 Cookie。
  • 账号和留言存在 Supabase（数据库与认证服务），浏览器与服务器之间走 HTTPS。
  • 登录状态保存在你自己浏览器的 localStorage 里；点「退出登录」即清除。

3. 谁看得到

  • 公开：你的昵称、简介、已通过审核的留言。
  • 仅你本人和站长：待审核、被拒绝的留言。
  • 仅站长：邮箱、IP、User-Agent、审核与封禁记录。

其他访客无法通过页面接口拿到你的邮箱、IP 或未公开的留言，这一点由数据库的行级权限策略保证，而不是靠前端隐藏。

4. 用来做什么

只用于展示留言、审核内容、防止刷屏与追责。不出售、不共享、不用于广告投放，也不做任何跨站跟踪。

5. 保留与删除

  • 留言可以随时自行撤回，撤回后不再公开展示。
  • 想彻底删除账号与全部留言，请发邮件到 zjh041106@qq.com，注明注册邮箱，一般 7 个工作日内处理完。
  • 被删除的留言在数据库中保留正文与操作记录，仅用于处理纠纷与滥用追溯，不再对外展示。

6. 第三方服务

  • Supabase：账号认证与数据存储。
  • GitHub Pages：静态页面托管。
  • 如果注册页启用了人机验证，会加载 Cloudflare Turnstile 的脚本，它只用于判断"是不是真人"，不参与内容分析。

7. 未成年人

未满 14 周岁的用户请在监护人陪同下使用，不要填写真实姓名、学校、住址等个人信息。

8. 变更与联系

本说明如有修改，会同步更新本页并在公告栏说明。任何疑问或数据相关请求，请联系 zjh041106@qq.com。
