Arthur Studio · 开源软件汉化

好软件， 不该有 语言门槛。

我们把优秀的开源工具译成自然、统一的简体中文：菜单、面板、提示与报错逐条对照，安装后打开就是中文界面。

我们在做什么

把语言这一层，
做得像不存在。

不是把英文藏起来，也不是只翻译几个按钮。汉化要覆盖菜单、面板、提示和报错，并让同一功能在全篇使用同一个译名。

01 / LOCALIZE

界面汉化

菜单、面板标题、按钮、右键菜单、提示与报错逐条对照原文翻译，术语统一，不改动布局与快捷键。

02 / PACKAGE

安装包整理

按安装版、便携版与补丁分别整理，标注基准版本与适用人群；腾讯云直链，无需提取码。

03 / DOCUMENT

来源与说明

写明官方版本、许可证、汉化范围与已知限制。截图保持原版界面，不伪造汉化后的软件截图。

Silverdaw 中文汉化

Windows 平台开源数字音频工作站（DAW）的完整中文本地化。官方原版、完整汉化版与汉化补丁三种获取方式均已整理发布。

  • 完整版基于官方 1.9.0 制作，中文资源已内置，无需另行打补丁
  • 补丁基于官方原版 1.10.0 制作，仅适配该版本
  • 许可开源免费发布，许可证 AGPL-3.0

    技术的初衷，
    是连接世界。

    技术的初衷是连接世界，但语言与网络的壁垒，常使优秀的技术产品难以抵达需要它的使用者。

    我是 Harvey，Arthur 工作室的创建者。建立这个站点，是为了提供一个低门槛的获取渠道：需要复杂网络环境才能下载的软件，改为直接获取；因英文界面而难以使用的优秀工具，提供完整的中文版本。

    无论是寻找工具，还是使用汉化后的完整界面，都可以从这里开始。
